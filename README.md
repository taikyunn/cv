## 職務要約

2021年からWebアプリケーション開発に従事。PHP / Laravelを中心としたバックエンド開発を軸に、認証基盤、サービス間のデータ連携、AWS / Terraformによるインフラ構築・運用、フロントエンドを含む機能開発を担当しています。

株式会社ココペリでは、認証基盤の刷新やデータ同期基盤の開発を推進。事業・他サービスの開発チームと要件を整理し、設計・実装から本番運用まで取り組んできました。2024年4月からは、自身を含む2〜4名の認証チームのリーダーとして、開発計画・優先順位の決定や設計・コードレビューも担当しています。

## 強み

- **要件を整理し、実装・運用まで進めること**：事業上の目的と利用場面を確認し、必要な機能や運用を具体化します。
- **サービス間の依存関係を整理すること**：認証基盤の独立リリースや、データ同期における通知・データ取得の分離に取り組んできました。
- **担当領域をまたいで機能を届けること**：バックエンドに加え、画面・DB・インフラの変更や関係部署との調整を担います。

## 職務経歴

### 株式会社ココペリ（2022年7月〜現在）

ソフトウェアエンジニア / 認証チームリーダー（2024年4月〜）

#### サービス間のデータ同期基盤

**【プロジェクト概要】**

サービス間のデータ更新を連携する同期基盤を開発。連携先の開発チームと協力し、要件調整から設計・実装・運用まで主担当として推進しました。現在、1サービスとの連携で本番稼働しています。

**【担当範囲】**

要件調整、設計、実装、レビュー、運用。チームメンバーにレビューを依頼しながら開発を進めました。

**【発揮したバリュー】**

- 「リアルタイムに反映したい」という要求に対し、利用場面を確認し、「画面の再読み込み時に更新内容を確認できること」まで要件を具体化しました。
- 通知側とデータ取得側の処理を分離する設計を提案し、関係者の合意を得て実装しました。
- ログの共通化と失敗時の通知を実装し、運用時に処理状況や問題を確認できるようにしました。
- 本番提供を通じて、事業上重要な顧客のサービス導入に貢献しました。

#### IdPの独立リリースに向けたインフラ整備

**【プロジェクト概要】**

サービス側のリリースに依存していた認証基盤（IdP）について、単独でリリースできる構成へ刷新。新サービスとのログイン連携を、認証チームで進められるようにしました。

**【担当範囲】**

経営層への提案、インフラリポジトリの設計・実装・運用。監視についてはSREと役割分担を整理しました。

**【発揮したバリュー】**

- サービスとのリリース依存を解消する仕組みを経営層へ提案し、導入を推進しました。
- Terraformを用いたインフラの構築・運用を主担当として進め、IdP単独でリリースできる構成を整備しました。
- 刷新後の新規ログイン連携1件を、開発開始から3日でリリースしました。
- 既存機能の移行では、利用状況の調査を提案。担当者を通じて顧客の業務を確認し、代替案の提案と合意形成を担当しました。CSへの問い合わせによる運用に置き換えることで、移行対象を整理しました。

#### 認証機能の拡充とチームでの開発推進

**【プロジェクト概要】**

金融機関の導入要件に対応するTOTP認証と、パスキー認証の開発に参加。TOTPは本番稼働し、導入要件を満たすことでサービス導入に貢献しました。パスキーは実装・テストを完了しており、事業上の優先順位により顧客への提案・本番提供は待機中です。

**【担当範囲】**

パスキー導入の起案、設計への参加、チーム向け勉強会の主催、リリース担当。実装主担当のメンバーが設計・実装・テストを進め、チームで設計検討とレビューを行いました。

**【発揮したバリュー】**

- パスキー認証の追加を起案し、対応デバイスや設定パラメーターの検討に参加しました。
- 認証技術の勉強会を主催し、チームで実装を進めるための知識共有を行いました。
- 新たに参加したメンバーが認証関連の開発を担当できるよう支援しました。また、新卒エンジニア向けに認証の基礎研修を実施しました。

#### その他の機能開発・改善

- **管理画面の初期パスワード設定フロー**：企業の経営者やサービス管理者が利用する機能を、Nuxt / TypeScriptによる画面からAPI・DBまで一貫して実装し、本番提供しました。
- **国・地域ごとの登録要件への対応**：サインアップ機能の画面・API・DBを改修し、国・地域に応じて入力必須項目を切り替える機能を本番提供しました。
- **Dockerイメージの軽量化**：設計、ソースコードの修正、デプロイを担当し、イメージサイズを約200MBから約80MBへ削減しました。

#### チーム運営

- 自身を含む2〜4名のチームで、他部署の要望収集、要件整理、開発計画、優先順位の決定、設計・コードレビューを担当しています。
- 他部署からの要望は、認証チームとしての意見を提示し、関係者と協議して対応方針を決めています。
- 会社のOKRに紐づく半期ごとのチーム目標を、2期連続で達成しました。
